- 예매 오픈 대기 기능은 사용자가 실제로 기다릴 판매 전 페이지에서 검증한다. 이미 판매 중인 공연의 회차 복원 테스트로 오픈 전 진입을 검증했다고 판단하지 않는다.
- 미오픈 화면의 유형을 조사할 때는 공식 오픈 예정 목록의 끝까지 확인한다. 상품 상세 화면, 예매 진입 화면, 판매 차수별 상태를 각각 기록하고 확인한 범위를 명시한다.
- 확장 기능은 사용자가 실행할 브라우저에서 검증하고 대상 OS를 구현 전에 확인한다.
- HTML의 data URL 추출 요청은 로컬 파일 선택과 구분한다. 대상 URL을 모르면 사용자가 선택한 현재 탭의 activeTab 권한으로 처리할 수 있는지 먼저 확인한다.
- 깨끗한 합성 문자열의 OCR 성공을 실제 캡챠 인식 품질의 근거로 삼지 않는다. 원본 이미지와 스크린샷 재표본화를 구분하고 전처리 조정에 쓰지 않은 별도 표본으로 정확도를 확인한다.
- OCR 실패가 반복되면 전처리된 픽셀을 먼저 확인한다. 색상 군집의 면적만으로 문자를 선택하지 않고 잡음·연결 영역을 함께 평가한다. 같은 실패 표본을 여러 크기에서 회귀 검증하고 비어 있지 않은 결과를 정답 검증 성공으로 표시하지 않는다.
