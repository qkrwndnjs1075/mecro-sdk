- 코드 조각만으로 실행 위치나 소유권을 단정하지 않는다. 수정 가능 여부를 판단하기 전에 현재 저장소에서 검사와 호출 경로를 찾고, 확인되지 않은 부분은 그대로 밝힌다.
- 자동 클릭 문제는 확장이 클릭을 호출하는지와 클릭 이후 화면 이동이 일어나는지를 각각 검증한다.
- 사이트가 `isTrusted`를 검사하면 페이지 JS로 우회하지 않는다. 자동 클릭은 `chrome.debugger`의 `Input.dispatchMouseEvent` 같은 실제 입력 경로로 보내고, 디버거 부착 실패 시 폴백과 수동 클릭 안내를 함께 남긴다.
- 버튼 좌표는 `getBoundingClientRect()`의 뷰포트 기준 중심을 쓴다. `offsetLeft`·`offsetTop`은 부모 기준이라 CDP 입력 좌표로 쓰지 않는다.
