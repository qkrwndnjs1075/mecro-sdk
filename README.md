# mecro-sdk

`tickets.interpark.com`과 `nol.yanolja.com/ticket/` 페이지에서 캡챠 팝업을 발견하면 결과 탭을 비활성 상태로 열어 OCR을 시작합니다. 같은 팝업의 빈 입력칸에 인식 결과를 자동으로 채우며 **입력완료 버튼은 누르지 않습니다**. 이미지가 바뀌면 다시 읽고 이전 자동 입력값은 지웁니다. 사용자가 직접 입력한 내용은 덮어쓰지 않습니다. 같은 원래 탭에서는 결과 탭을 재사용하며 페이지가 이동하면 다시 연결합니다.

결과 탭에는 원본 미리보기와 data URL, OCR로 읽은 영문·숫자가 표시됩니다. 결과 탭을 닫으면 현재 인식 연결이 끝나고 다음 이미지가 발견되면 다시 열립니다. 자동 시작 범위 밖의 페이지에서는 확장 메뉴의 **팝업 이미지 추출**로 시작할 수 있습니다. 최상위 문서만 지원하며 iframe 내부는 지원하지 않습니다. 인식 결과는 이미지와 대조해 확인하세요. 확장 업데이트 후에는 확장과 대상 페이지를 새로고침해야 자동 감지가 적용됩니다.

Windows와 macOS의 Chrome에서 확장에 포함된 영어 OCR 엔진이 기기에서 이미지를 읽습니다. 파일 선택 없이 추출한 이미지를 사용합니다.

OCR 전에 색상 군집과 연결 영역의 형태로 문자와 배경·잡음을 분리한 뒤 여백을 넣어 확대합니다. 원본 미리보기와 data URL은 보존합니다. 결과는 인식 후보이며 작은 글자나 복잡한 배경에서는 여전히 오인식할 수 있습니다. [검증 방법과 한계](docs/ocr-validation.md)를 참고하세요.

OCR 배포 파일은 [Tesseract.js](https://github.com/naptha/tesseract.js) 6.0.1, [tesseract.js-core](https://github.com/naptha/tesseract.js-core) 6.1.2의 LSTM 코어와 [영어 모델](https://www.npmjs.com/package/@tesseract.js-data/eng) 1.0.0의 `4.0.0_best_int`를 사용합니다.

NOL 인터파크에서 아직 열리지 않은 일반예매를 기다리는 Chrome 확장입니다.

1. `chrome://extensions`에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 [extension](extension) 폴더를 선택합니다. 기존 설치를 업데이트할 때는 확장과 예매 페이지를 한 번씩 새로고침합니다.
2. 상품 상세 또는 예매 대기 페이지를 엽니다. 날짜 달력이 보이면 원하는 날짜와 회차를 직접 선택합니다.
3. 확장 팝업에 표시된 상품과 **일반예매 오픈 일시(한국시간)**를 확인하고 **일반예매 대기 시작**을 누릅니다. 대기 중에는 팝업을 닫아도 됩니다. 오픈 직전에는 예매 탭을 화면에 띄워 두세요.
4. 상품 상세에서 시작하면 오픈 시각에 한 번 새로고침합니다. 선택한 회차가 있으면 복원하고 예매 버튼을 누릅니다. 예매 게이트에서는 사이트가 일반예매 버튼을 활성화할 때까지 기다렸다 한 번 누릅니다.

이미 열린 일반예매는 시작할 수 없습니다. 선예매·회원 인증 버튼도 누르지 않습니다. 게이트에 선예매 시각이나 ‘판매 예정입니다’만 표시된다면 일반예매 일정이 명시된 상품 상세 페이지에서 시작하세요. 추가 판매분과 선택한 회차의 관계가 불분명한 달력 화면에서는 대기를 제한합니다.

시각은 공개 페이지의 HTTP 응답 날짜와 캐시 경과 시간으로 추정합니다. 게이트에서 일반예매 남은 시간이 표시되면 해당 카운트다운도 읽습니다. 네트워크 지연, 탭 비활성화, 절전 상태에 따라 실행이 늦어질 수 있습니다.

예매처 전용 코드는 [providers/nol-interpark](extension/providers/nol-interpark)에 있습니다. 예매 버튼을 누른 뒤 대기열이나 예매창을 확인하세요.
